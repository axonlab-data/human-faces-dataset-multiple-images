# human-faces-dataset-multiple-images
1,000+ people, 10,000+ files: 8 photos per person + 2 videos
## You can find a full sample of this dataset on [Kaggle](https://www.kaggle.com/datasets/axondata/face-recognition-dataset-selfies-videos)

## Key Highlights:
- 1,000+ unique individuals across ages, genders, and ethnicities
- 10,000+ total files (photos + videos)
- Historic photos combined with current selfies
- 8 diverse images captured across different conditions
- 2 videos per person: zoom-in and head turn

## Structured Metadata Included (metadata_public_sample.json)
The dataset includes file with structured participant information for easy filtering and analysis:
- **Demographics:** age, gender, ethnicity
- **Device Information:** os (android/ios/windows), device type (phone/pc), device_model
